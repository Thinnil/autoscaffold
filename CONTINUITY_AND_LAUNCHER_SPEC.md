- **Document Version**: 2.0.0
- **Pipeline Stage**: Prompt Polisher (Orchestai Multi-Agent Pipeline)
- **Target Subsystem**: AutoScaffold Suite (`autoscaffold`, `install.sh`, `scripts/chimera_scaffold.py`, `chimera_scaffold.sh`, `scripts/pse_pdb_extractor.py`)
- **Primary AI & Structural Engines**: RFdiffusion, ProteinMPNN, ColabFold / AlphaFold2, Biopython / PyMOL Structural Parsers

## 1. Executive Summary & Problem Formulation

In real-world protein engineering workflows (e.g. grafting an Aryl Hydrocarbon Receptor [AHR] ligand-binding domain or client motif onto or between Hsp90 chaperone complexes such as PDB 7ZUB), computational biologists encounter two major hurdles with automated scaffolding pipelines:

1. **CLI Portability & Execution Friction**:
   Researchers operate across disparate project directories on cluster nodes or workstations. AutoScaffold must be invokable globally as `autoscaffold` from any working directory (`$PWD`), reading relative input structures and depositing run artifacts cleanly in the active working directory, without relying on hardcoded repository paths.

2. **Structural Discontinuity, Unphysical Gaps & PyMOL "Dotted Lines"**:
   When chimeric models generated by RFdiffusion are inspected in PyMOL or ChimeraX, users observe:
   - Preserved receptor cores surrounded by **dashed/dotted lines** bridging to adjacent segments.
   - Large empty spaces/voids where density should reside.
   - Broken polypeptide backbones where donor residues scattered across multiple chains (e.g. Hsp90 homodimer chains A and B) were artificially treated as a single continuous chain.

This specification details the mathematical, biophysical, and architectural solutions required to resolve these issues completely.

## 2. Global CLI Launcher Architecture (`autoscaffold`)

### 2.1 Design Requirements
- **Location-agnostic execution**: Running `autoscaffold [subcommand] [flags]` from `/home/user/experiments/run_42/` must execute the pipeline using tool configurations and Python environments located in the repository (`AUTOSCAFFOLD_HOME`), while treating `/home/user/experiments/run_42/` as the root for all relative file inputs (`--input ./session.pse`) and output generation (`./outputs/`).
- **Zero sudo / unprivileged installation**: By default, install into `~/.local/bin/autoscaffold`. If `~/.local/bin` is not on the user's `PATH`, provide an automated export to `~/.bashrc` / `~/.zshrc`.
- **Transparent Subcommand Passthrough**: Support both interactive TUI launching and full headless execution:
  - `autoscaffold` (launches interactive suite menu)
  - `autoscaffold chimera --input ...`
  - `autoscaffold motif ...`
  - `autoscaffold binder ...`
  - `autoscaffold discontinuous ...`
  - `autoscaffold diagnostics`
  - `autoscaffold update`

### 2.2 Canonical Path Resolution Implementation
The global wrapper script resolves the physical directory of AutoScaffold even if invoked through symlinks:

```bash
#!/usr/bin/env bash
# autoscaffold - Global CLI Launcher
set -e

# Resolve true canonical path across symlinks
resolve_target() {
    local source="${BASH_SOURCE[0]}"
    while [ -h "$source" ]; do
        local dir="$(cd -P "$(dirname "$source")" && pwd)"
        source="$(readlink "$source")"
        [[ $source != /* ]] && source="$dir/$source"
    done
    echo "$(cd -P "$(dirname "$source")" && pwd)"
}

LAUNCHER_DIR="$(resolve_target)"
# If installed via symlink into ~/.local/bin, resolve target repository root
if [ -f "$LAUNCHER_DIR/autoscaffold_suite.sh" ]; then
    AUTOSCAFFOLD_HOME="$LAUNCHER_DIR"
elif [ -n "$AUTOSCAFFOLD_DIR" ] && [ -f "$AUTOSCAFFOLD_DIR/autoscaffold_suite.sh" ]; then
    AUTOSCAFFOLD_HOME="$AUTOSCAFFOLD_DIR"
else
    # Fallback to configured install target or parent
    PARENT_DIR="$(dirname "$LAUNCHER_DIR")"
    if [ -f "$PARENT_DIR/autoscaffold_suite.sh" ]; then
        AUTOSCAFFOLD_HOME="$PARENT_DIR"
    else
        echo -e "\033[0;31m[ERROR] AutoScaffold repository root could not be located.\033[0m"
        echo -e "Please set export AUTOSCAFFOLD_DIR=/path/to/autoscaffold in your environment."
        exit 1
    fi
fi

# Export canonical home while preserving caller's current working directory
export AUTOSCAFFOLD_HOME
export AUTOSCAFFOLD_CALLER_PWD="$(pwd)"

# Execute master suite with user arguments
exec bash "$AUTOSCAFFOLD_HOME/autoscaffold_suite.sh" "$@"
```

## 3. Biophysical Analysis of Backbone Discontinuity & PyMOL Dotted Lines

### 3.1 Molecular Viewer Chemical Bond Thresholds
In crystallographic PDB representations, molecular graphics software (PyMOL, ChimeraX, VMD) builds covalent backbone connectivity using distance criteria:
- **Trans Peptide Bond ($C_i - N_{i+1}$)**:
  - Ideal bond length: $\approx 1.33 \text{ Å}$.
  - PyMOL bonding threshold: $d(C_i, N_{i+1}) \le 2.0 - 2.5 \text{ Å}$.
- **$C_\alpha(i) - C_\alpha(i+1)$ Pseudo-bond**:
  - Ideal $C_\alpha - C_\alpha$ distance: $3.80 \text{ Å}$ (trans conformation).
  - PyMOL threshold: $d(C_\alpha(i), C_\alpha(i+1)) \le 4.2 \text{ Å}$.

**Root Cause of Dotted Lines**:
When adjacent residues in the PDB output file have a $C-N$ distance $> 2.5 \text{ Å}$ or $C_\alpha - C_\alpha$ distance $> 4.2 \text{ Å}$, PyMOL detects a **covalent chain break**. To alert the user to unphysical models or missing loop density, PyMOL does NOT render a solid ribbon or cylinder; instead, it renders **dashed / dotted connecting vectors** across the gap.

### 3.2 The Geometric Gap & Inadequate Linker Budgeting
In standard chimera scaffolding, users attempt to fuse a donor domain (e.g. residue 30–120) into a vessel receptor (e.g. residue 1–300) with default linker flags (e.g. `--linker-n 6-10` or `--linker-c 6-10`).

If the physical Euclidean distance between the donor terminus and the vessel terminus is $D = 48.0 \text{ Å}$:
1. **Fully Extended Maximum Span**:
   A polypeptide in maximum $\beta$-strand / fully extended trans conformation has a maximum span of $3.8 \text{ Å}$ per residue.
   $$\text{Max Extension of 10 residues} = 10 \times 3.8 \text{ Å} = 38.0 \text{ Å}$$
   Because $38.0 \text{ Å} < 48.0 \text{ Å}$, it is **geometrically impossible** for 10 residues to bridge a 48 Å gap.
2. **RFdiffusion Failure Mode**:
   When forced to generate 10 residues across a 48 Å gap while keeping anchor coordinates pinned (`noise=0.0`), RFdiffusion's equivariant graph neural network attempts to minimize contradictory spatial constraints. The denoiser stretches virtual $C_\alpha - C_\alpha$ bonds to unphysical distances ($> 5.5 \text{ Å}$), causing:
   - Chain breaks / dashed lines in PyMOL.
   - Large empty solvent voids devoid of packing density.
   - Complete collapse of downstream AlphaFold2 / ColabFold pLDDT validation.

## 4. Euclidean Distance-Aware Linker Budgeting Engine

### 4.1 Anchor Coordinate Determination
Prior to constructing RFdiffusion contigs, `chimera_scaffold.py` inspects the exact 3D coordinates of anchor atoms in the seed structure:

1. **Mode `ligate_nterm` (Donor fused before Vessel N-terminus)**:
   - $\mathbf{x}_{\text{donor\_C}}$: $C_\alpha$ and $C$ coordinates of Donor C-terminal residue.
   - $\mathbf{x}_{\text{vessel\_N}}$: $C_\alpha$ and $N$ coordinates of Vessel N-terminal residue.
   - Gap Distance: $d = \|\mathbf{x}_{\text{vessel\_N}} - \mathbf{x}_{\text{donor\_C}}\|_2$.

2. **Mode `ligate_cterm` (Donor fused after Vessel C-terminus)**:
   - $\mathbf{x}_{\text{vessel\_C}}$: $C_\alpha$ and $C$ coordinates of Vessel C-terminal residue.
   - $\mathbf{x}_{\text{donor\_N}}$: $C_\alpha$ and $N$ coordinates of Donor N-terminal residue.
   - Gap Distance: $d = \|\mathbf{x}_{\text{donor\_N}} - \mathbf{x}_{\text{vessel\_C}}\|_2$.

3. **Mode `replace` / `graft` (Donor substituted for Vessel segment $[R_{\text{start}}, R_{\text{end}}]$)**:
   - **N-terminal Junction**:
     - $\mathbf{x}_{\text{vessel\_pre}}$: $C_\alpha$ of Vessel residue $(R_{\text{start}} - 1)$.
     - $\mathbf{x}_{\text{donor\_N}}$: $C_\alpha$ of Donor N-terminal residue.
     - $d_N = \|\mathbf{x}_{\text{donor\_N}} - \mathbf{x}_{\text{vessel\_pre}}\|_2$.
   - **C-terminal Junction**:
     - $\mathbf{x}_{\text{donor\_C}}$: $C_\alpha$ of Donor C-terminal residue.
     - $\mathbf{x}_{\text{vessel\_post}}$: $C_\alpha$ of Vessel residue $(R_{\text{end}} + 1)$.
     - $d_C = \|\mathbf{x}_{\text{vessel\_post}} - \mathbf{x}_{\text{donor\_C}}\|_2$.

4. **Mode `insert_loop` (Donor inserted into Vessel after residue $S$)**:
   - $\mathbf{x}_{\text{vessel\_left}}$: $C_\alpha$ of Vessel residue $S$.
   - $\mathbf{x}_{\text{vessel\_right}}$: $C_\alpha$ of Vessel residue $(S + 1)$.
   - $d_N = \|\mathbf{x}_{\text{donor\_N}} - \mathbf{x}_{\text{vessel\_left}}\|_2$.
   - $d_C = \|\mathbf{x}_{\text{vessel\_right}} - \mathbf{x}_{\text{donor\_C}}\|_2$.

### 4.2 Mathematical Formulations for Linker Lengths
For any anchor pair separated by Euclidean distance $d$ (in Ångströms):

1. **Absolute Theoretical Minimum ($L_{\text{ext\_min}}$)**:
   Based on maximal extended backbone limit ($3.8 \text{ Å}$/residue):
   $$L_{\text{ext\_min}} = \lceil d / 3.8 \rceil$$
   *(Note: A linker at $L_{\text{ext\_min}}$ must adopt a rigid, fully stretched conformation and cannot form secondary structure or pack against the protein surface).*

2. **Physiologically Realistic Globular Minimum ($L_{\text{glob\_min}}$)**:
   Based on average $C_\alpha - C_\alpha$ spatial persistence in globular proteins ($3.0 \text{ Å}$/residue for relaxed loops):
   $$L_{\text{glob\_min}} = \lceil d / 3.0 \rceil$$

3. **Recommended Sampling Range**:
   To allow RFdiffusion sufficient conformational freedom to form stable secondary structures (helices, beta-hairpins) that fill hydrophobic voids rather than spanning empty air:
   $$L_{\text{range\_min}} = L_{\text{glob\_min}}$$
   $$L_{\text{range\_max}} = L_{\text{glob\_min}} + \max\left(6, \; \lceil 0.25 \cdot L_{\text{glob\_min}} \rceil\right)$$

#### Numerical Reference Table:
| Euclidean Gap ($d$) | $L_{\text{ext\_min}}$ (3.8 Å) | $L_{\text{glob\_min}}$ (3.0 Å) | Recommended Contig Range | Structural Character |
|:---:|:---:|:---:|:---:|:---|
| **$8.0 \text{ Å}$** | 3 aa | 3 aa | `3-8` | Short flexible turn/loop |
| **$15.0 \text{ Å}$** | 4 aa | 5 aa | `5-12` | Structured hairpin loop |
| **$25.0 \text{ Å}$** | 7 aa | 9 aa | `9-16` | Connecting loop or mini $\alpha$-helix |
| **$40.0 \text{ Å}$** | 11 aa | 14 aa | `14-22` | Helix-turn-helix or small domain |
| **$60.0 \text{ Å}$** | 16 aa | 20 aa | `20-30` | De novo packing subdomain |

### 4.3 Automated Linker Recommendation & Warning System
In `chimera_scaffold.py`:
- If `--linker-n auto` or `--linker-c auto` is provided (or if running interactively), compute and inject the recommended range.
- If a user explicitly specifies a linker whose maximum length is strictly less than $L_{\text{ext\_min}}$:
  ```text
  [WARNING] Physical Euclidean distance between Vessel (res 145) and Donor (res 20) is 42.6 Å.
  Specified linker length '6-10' is physically incapable of spanning 42.6 Å (max reach = 38.0 Å).
  This WILL produce unphysical chain breaks and dotted lines in PyMOL!
  --> Auto-adjusting linker range to physically feasible span: '15-22'
  ```

## 5. Multi-Chain Complexes & Crystallographic Discontinuity Handling

### 5.1 Realities of Cryo-EM & X-Ray Complexes (e.g. 7ZUB)
Structures such as PDB 7ZUB (AHR-Hsp90-p23-XAP2 complex) feature:
1. **Multi-Chains**: Hsp90 operates as a homodimer (Chain A and Chain B), interacting with AHR (Chain D) and cochaperones.
2. **Scattered Residue Selections**: When a user selects "the active site" or "donor residues", residues often belong to multiple distinct chains or disparate spatial epitopes.
3. **Internal Unmodeled Loops / Coordinate Gaps**: Within a single chain (e.g. Hsp90), flexible loops (e.g. residues 220–270) often have missing electron density and are absent from the PDB file.

### 5.2 Algorithmic Discontinuity Detection
Instead of treating chain residue ranges as simple integers $[R_{\text{min}}, R_{\text{max}}]$, `chimera_scaffold.py` parses coordinate arrays and identifies internal breaks:

```python
def extract_contiguous_segments(atoms: List[Dict]) -> List[Tuple[str, int, int]]:
    """
    Groups atoms into strictly contiguous structural segments where:
    1. Chain ID is identical.
    2. Residue numbering is sequential (res_k+1 == res_k + 1).
    3. C(k) - N(k+1) Euclidean distance <= 2.2 Å (or CA(k) - CA(k+1) <= 4.2 Å).
    """
```

### 5.3 Contig Assembly for Multi-Chain & Discontinuous Topologies
1. **Case A: Multi-segment Donor within a Single Designed Chain**:
   If the user wishes to fuse scattered donor residues $D_1$ and $D_2$ into a single polypeptide:
   - Measure Euclidean distance $d(D_1^{\text{end}}, D_2^{\text{start}})$.
   - Insert an internal connecting de novo linker $L_{\text{internal}}$ computed from $d$:
     `D1-50 / 8-12 / D80-120`
   - If distance $d > 50 \text{ Å}$ and connecting them within a single chain is structurally detrimental, notify the user.

2. **Case B: Multi-Chain Heterooligomer Preservation (`/0 ` Chain Breaks)**:
   If donor or vessel involves multiple distinct chains (e.g. Chain A and Chain B of Hsp90) that must remain separate non-covalent partners:
   - RFdiffusion requires the `/0 ` delimiter to signal a chain break without covalent connection:
     `contigmap.contigs=[V1-220/8-12/D30-80/8-12/V271-690/0 B1-690]`
   - This prevents RFdiffusion from artificially trying to connect two unrelated chains with a covalent bond.

def calculate_anchor_distance(coord1: np.ndarray, coord2: np.ndarray) -> float:

def compute_recommended_linker(distance_angstrom: float) -> Tuple[int, int]:
    """
    Calculates physically realistic linker residue bounds:
    min_len = ceil(distance / 3.0)
    max_len = min_len + max(6, ceil(0.25 * min_len))
